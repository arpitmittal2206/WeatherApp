# WeatherApp 🌤️

This is a simple JavaScript-based Weather App that fetches real-time weather data using the OpenWeatherMap API. Users can enter a city name to get current temperature, humidity, and weather conditions.

## Features
- Live weather data
- City-based search
- Responsive design (add CSS if needed)

## Technologies
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Setup
1. Clone the repo
2. Replace `'YOUR_API_KEY'` with your actual OpenWeatherMap API key
3. Open `index.html` in your browser

## API Reference
[OpenWeatherMap API Docs](https://openweathermap.org/api)
